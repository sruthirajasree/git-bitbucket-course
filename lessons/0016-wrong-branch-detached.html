Lesson 0016 · Phase 4: Undo and recover · 14 min

Wrong branch, amend and detached HEAD

You will be able to: recover from the three most common daily slips without losing a commit.

1. Committed on staging instead of a feature branch (unpushed)

Branches are labels. Put a new label on your commits, then move staging's label back.

Order matters: create the new branch first. Check with git log feature/x --oneline before the hard reset.

2. Forgot something in the last commit (unpushed)

git add forgotten.py
git commit --amend --no-edit     # or drop --no-edit to fix the message

Amend replaces the last commit with a new one. If already pushed it needs a force push: prefer a small new commit.

3. Detached HEAD

You checked out a commit/tag/origin/x directly. HEAD points at a commit, not a branch; new commits belong to no branch and are lost when you switch away.

git switch -c rescue/my-work    # keep the work (do it before leaving!)
git switch -                    # or just go back if you only looked around
