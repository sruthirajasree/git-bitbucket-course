Read before you fix: status, log, diff

You will be able to: run a three-command health check that tells you exactly where you are before any recovery.

Most Git disasters come from running a fix before reading the state. Make this your reflex:

git status -sb                         # branch, ahead/behind, changed files
git log --oneline --graph --decorate --all -15   # the shape of history
git diff            # unstaged edits
git diff --staged   # what the next commit contains
