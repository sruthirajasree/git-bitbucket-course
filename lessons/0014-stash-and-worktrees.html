Lesson 0014 · Phase 3: Staying in sync · 12 min

Switching tasks: stash and worktrees

You will be able to: park unfinished work and context-switch without committing junk.

An urgent bug arrives while you have half-done edits. Three options:

ToolUse whenCommand
Commit WIPYou are on your own branchgit commit -am 'WIP' (squash later)
StashQuick switch, back soongit stash push -u -m 'PROJ-1234 wip'
WorktreeNeed both open at once (review, long hotfix)git worktree add ../hotfix -b bugfix/PROJ-2000 origin/staging

Stash cheatsheet

git stash push -u -m "msg"   # -u also shelves untracked files
git stash list
git stash show -p stash@{0}  # peek
git stash pop                # apply newest, drop it on success
git stash apply stash@{1}    # apply but keep it
git stash drop stash@{0}
If pop conflicts, the stash is not dropped: resolve, git add, then git stash drop yourself.
Stashes are local only and easy to forget. Do not keep work there for days: commit it on a branch.
