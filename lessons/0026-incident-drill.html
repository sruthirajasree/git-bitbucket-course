Capstone: incident drill and decision tree

You will be able to: work from symptom to fix under pressure, using the decision tree and then the full scenario trainer.

Print this decision tree. Every real problem starts with git status -sb, then follows one branch.

START: git status -sb ; git log --oneline --graph --all -15

Can't connect / auth error ............................. lesson 5
Push rejected ("fetch first")........................... lesson 10  (pull --rebase, then push)
Pull says diverged / would be overwritten .............. lessons 10, 14
Status says UU / "Unmerged paths" ...................... lesson 12  (resolve, add, commit)
"rebase in progress" ................................... lesson 13  (resolve, add, --continue | --abort)

Fix needed on another branch ........................... lesson 20  (cherry-pick)
Secret committed ....................................... lesson 22  (ROTATE, then clean)
PR can't merge ......................................... lessons 7, 24 (merge checks)
PR conflicts / out of date ............................. lessons 11-13
Dependent PR after squash .............................. lesson 23  (rebase --onto)
Hook declined push ..................................... lesson 24

Before any destructive command

  • git status: do I have uncommitted work? stash it.
  • git branch backup/$(date +%F): free undo.
  • Is it pushed? Is it shared? Pushed and shared means revert, not reset.
  • Am I on the right branch? git branch --show-current.

Final practice: all labs in a row

Run each lab without hints, then check. Aim for 13 of 13. Order of difficulty:

  • Easy: amend, wrong-branch, detached, squash-wip, secret
  • Medium: rejected, stash-pull, revert-pushed, squash-cleanup, backport
  • Hard: conflict-merge, conflict-rebase, lost-commits
