# Git with Bitbucket

Interactive course, hands-on terminal simulator, and a searchable 60-situation handbook for working with Git and Bitbucket (pull requests into `staging`).

Open `index.html` (or the GitHub Pages site). Everything is static HTML/JS; no build step.

- 26 lessons with commit-graph diagrams and multiple-choice quizzes
- 13 hands-on drills (in-browser simulator) plus real-git sandbox labs: `labs/lab.sh`
- Printable references: decision tree, undo ladder, cheatsheet, PR checklist, glossary

Example host and project names are placeholders.
