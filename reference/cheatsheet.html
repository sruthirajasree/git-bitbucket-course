Command cheatsheet

The commands from the course, grouped by purpose.

Look

git status -sb
git log --oneline --graph --decorate --all -15
git diff / git diff --staged / git diff origin/staging...HEAD
git blame -L a,b f ; git log -S"str" ; git reflog

Daily loop

git switch staging && git pull --ff-only
git switch -c feature/PROJ-N-desc
git add -p ; git commit -m "PROJ-N: msg"
git push -u origin HEAD

Sync

git fetch --prune
git pull --rebase | git pull --ff-only
git merge origin/staging | git rebase origin/staging
git push --force-with-lease   # only after rewriting your own branch

Conflict

git status ; edit ; git add f ; git commit | git rebase --continue
git merge --abort | git rebase --abort | git cherry-pick --abort

Park work

git stash push -u -m msg ; git stash list ; git stash pop
git worktree add ../x -b bugfix/PROJ-N origin/staging

Undo / recover

git restore f ; git restore --staged f
git reset --soft|--mixed|--hard HEAD~1
git revert <sha> ; git revert -m 1 <merge-sha>
git reflog ; git reset --hard HEAD@{n} ; git reset --hard ORIG_HEAD

Rewrite / copy

git commit --amend ; git rebase -i origin/staging
git reset --soft origin/staging && git commit -m ...
git cherry-pick -x <sha> ; git rebase --onto origin/staging <oldbase> branch

Cleanup / release

git branch -d x ; git branch -D x ; git push origin --delete x
git tag -a v1.0.0 -m msg ; git push origin v1.0.0
