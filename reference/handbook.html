Git + Bitbucket Handbook

Situation-first. Find your symptom, run the Diagnose commands, then the Do this block. Search or filter below. Print-friendly.

Golden rules
  1. Read before you fix: git status -sb, git log --oneline --graph --all -15.
  2. Unpushed history is yours to rewrite. Pushed shared history is not: use revert.
  3. Before anything destructive, make a safety branch: git branch backup/x.
  4. Committed work is almost never lost: git reflog. Uncommitted work is.
  5. Never --force; use --force-with-lease, and only on your own branch.
