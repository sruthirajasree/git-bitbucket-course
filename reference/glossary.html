Glossary

Every term, defined once.

TermMeaning
BranchA movable label pointing at a commit.
Branch permissionsServer rules limiting who can push/rewrite a branch.
Cherry-pickCopy one commit's diff onto the current branch as a new commit.
CloudBitbucket at bitbucket.org.
CommitSnapshot of the project plus pointer(s) to parent commit(s).
ConflictBoth sides changed the same lines; a human picks the result.
Dangling commitA commit no branch/tag points at; recoverable until garbage-collected.
Data CenterSelf-hosted Bitbucket (formerly Server).
Detached HEADHEAD points at a commit instead of a branch; new commits are unnamed.
Fast-forwardMove a branch label forward along a straight line; no new commit.
FetchDownload remote commits and update bookmarks; changes no branch.
Force pushOverwrite the remote branch with yours; dangerous. Prefer --force-with-lease.
HEADYour current position: usually a branch, sometimes a raw commit (detached).
Hook (pre-receive)Server script that can reject a push.
Index / staging areaWhat the next commit will contain; filled by git add.
Merge checksServer rules (approvals, builds, tasks) that must pass before merging.
Merge commitA commit with two parents that joins two lines of history.
Non-fast-forwardPush or merge where histories diverged; rejected for pushes.
ORIG_HEADPointer to where HEAD was before a risky operation like rebase or merge.
PullFetch plus merge (or rebase) into the current branch.
Pull request (PR)Bitbucket record asking to merge a source branch into a target branch; includes review, approvals, checks.
PushSend your commits to the remote and move its branch.
RebaseCopy commits onto a new base; creates new commit ids.
ReflogLocal log of everywhere HEAD and branches have been; the recovery tool.
RemoteA named URL of another copy of the repo, usually origin = Bitbucket.
Remote-tracking branchLocal bookmark like origin/staging showing where the remote branch was at last fetch.
ResetMove the current branch label (and optionally index/files) to another commit.
RevertCreate a new commit that undoes an earlier one.
SquashCombine many commits into one new commit.
StashLocal shelf for uncommitted changes.
TagA fixed label on a commit, e.g. a release.
Target / destination branchThe branch a PR will merge into (here: staging).
UpstreamThe remote branch your local branch tracks (set with push -u).
Working treeThe files on disk you edit.
WorktreeAn extra working folder attached to the same repo.
