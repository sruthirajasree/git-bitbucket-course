Decision tree

Start every incident with git status -sb.

Symptom                                      -> First move
-------------------------------------------------------------------------------
Permission denied / auth failed              -> ssh -vT, add key / new token         (L5)
Push rejected (fetch first)                  -> git pull --rebase ; git push         (L10)
Diverged                                     -> pull --rebase (own) / merge (shared) (L10-11)
Pull blocked by local changes                -> stash, pull, pop                     (L14)
Conflict markers                             -> edit, add, commit/--continue         (L12-13)
Wrong branch, unpushed                       -> switch -c new ; reset staging        (L16)
Detached HEAD                                -> switch -c rescue/x                   (L16)
Lost commits                                 -> reflog, reset --hard HEAD@{n}        (L17)
Bad commit pushed                            -> revert                               (L19)
Bad merge pushed                             -> revert -m 1                          (L19)
Fix needed on release                        -> cherry-pick -x                       (L20)
Secret pushed                                -> ROTATE first, then admin/filter-repo (L22)
Hook declined                                -> feature branch + PR                  (L24)
PR can't merge                               -> read merge checks                    (L7)
Stacked PR after squash                      -> rebase --onto                        (L23)
