Undo ladder

Pick by where the change is.

The change is...Undo withNotes
Edited, unstagedgit restore fEdits lost for good
Stagedgit restore --staged fEdits kept
Committed, unpushed, keep edits stagedgit reset --soft HEAD~1
Committed, unpushed, keep edits unstagedgit reset HEAD~1
Committed, unpushed, discardgit reset --hard HEAD~1Reflog can recover the commit
Last commit message/files wrong, unpushedgit commit --amend
Pushed/shared commitgit revert <sha>Never rewrite shared history
Merge commit pushedgit revert -m 1 <sha>Re-merge trap
Lost commitsgit reflog + git reset --hard HEAD@{n}Local only
Deleted branchgit branch name <sha>
Bad rebase/merge just donegit reset --hard ORIG_HEAD
Mid-operation, want outgit merge|rebase|cherry-pick|revert --abort
Untracked junkgit clean -nd then -fdDeletes permanently
Make branch equal remotegit branch backup/x; git fetch; git reset --hard origin/xBack up first
